## Featured Projects

### 1. DocuMind AI — AI-Powered Document Intelligence

A full-stack AI application that transforms uploaded PDF documents into searchable knowledge, enabling users to retrieve relevant information and receive AI-generated answers with source references.

**Highlights**

- Secure user registration and login with JWT authentication
- PDF upload and text extraction
- Page-aware document chunking and storage
- Semantic and keyword-based hybrid search
- AI-generated answers grounded in document content
- Source references with filenames and page citations
- PostgreSQL database integration
- Cloud deployment with separate frontend and backend services

**Tech Stack:** Next.js · React · TypeScript · Node.js · Express · PostgreSQL · Gemini API · JWT

**Deployment:** Vercel (Frontend) · Render (Backend) · Neon (PostgreSQL)

**Links:** [Live Demo](https://documind-ai-ashy-tau.vercel.app/) · [Source Code](https://github.com/nirbhayyyy18/documind-ai)
